## 一、结论先行

1. **数据面齐备且有富余**：港股 T-1（2026-10-14）新鲜数据包括 —— 日线行情（daily_forward 11622 分区/1110 万行）、l1_factors 因子（130+ 列/2170 只/日）、南向持股因子（9 列/1018 只）、CCASS 持股因子（24 列/2778 只）、恒生行业分类（31 类/2784 只）。**下钻与机会评分全部可用现有数据实现，无需新增数据采集。**
2. **热力图升级 = A 股已验证模式平移**：共享组件 `SectorHeatmapChart` 已具备 `onItemClick/colorOf/tooltipExtraOf` 全部所需 props；后端照 A 股 `/heatmap/drill` 模式新增一个端点。L1 行业层面积=行业总成交额，L2 个股层面积=个股成交额，**同一份快照父子求和自洽**。
3. **个股弹窗机制现成**：`StockTerminalWindow`（market="HK"）已支持港股个股终端（K 线 + 7 Tab 详情），目前港股页只有顶栏搜索框在用。共享行组件 `RankRow` 加一个可选 `onClick` 即可把**全部榜单面板**（南向/CCASS/估值/盈利龙头/机会雷达）的行接上弹窗，另加 L2 热力图色块点击。
4. **预测性内容必须自建且必须诚实**：港股**无生产模型信号**（`engine_signal_scores` 无 HK 行；仅有的 2 个 HK 模型是 9 月初「hk-mini-13-0902」验证实验产物，已停更）。预测面设计为**可解释的因子复合评分（机会雷达）**：动量/趋势/南向/筹码/流动性/风险六柱，每柱全市场横截面分位合成，实施时用历史分区做 IC 快测并把结果如实写入交付报告（无效也如实说）。同时**不使用**「主力净额」（港股无 L2，不存在该数据；l1 的 `flow_net_amount` 是 Σ5d sign(close.diff())×amount 的方向性成交额代理，不做资金流展示）。
5. **顺手把两处结构性停更修掉**：`ah_premium`（H/A 溢价，停 2026-08-27）与估值快照（停 2026-09-12）是「Tab 看起来专业但数据是陈的」的最大隐藏雷。`ah_premium` 生产者 `quanthk_extra_datasets.py` 存在但不在日链 —— 本任务把「重新纳入日链」列为 S3（可选项，独立于主功能）。

### 3.3 明确不做（防跑偏）

1. **不做「主力净额 / 主力资金」** —— 港股无 L2 逐笔，该数据不存在；`flow_net_amount`（Σ5d sign(close.diff())×amount）是方向性成交额代理，只可作因子分柱输入之一（且须命名「方向性成交额」），不得以上位概念展示
2. **不做市值加权/市值过滤** —— l1 市值列全 0，热力图面积一律成交额
3. **不显示 PE/PB/换手率**（l1 垃圾列）—— 估值面继续用现有 `valuation` 快照口径（含停更标注）
4. **不造模型信号** —— 机会分是因子复合评分，UI 文案和文档都不称「模型预测」；报告里给出 IC 快测结果，无效如实说
5. **不做盘中/分钟级** —— 本页是 T-1 日频分析面（盘中实时在实盘栏，不在此范围）
6. **不用港交所官方行业** —— sector/ 数据空，继续 akshare_profile 恒生行业（31 类）
7. **不做仙股/老千股展示** —— 机会榜设入榜门槛（见 4.3）

## 四、口径纪律（港股专属，先立规矩再写代码）

1. **涨跌幅**：`close_t/close_{t-1}-1`，clip ±100（daily_forward 不复权、含跳变）；**无涨跌停概念，不套用 A 股 ±10/±20 档位**；`published_at` 去重取最新发布。
2. **面积口径（父子自洽）**：L1 行业面积 = 成分当日成交额求和（亿）；L2 个股面积 = 个股当日成交额（亿）。**两层级在同一函数内从同一份 `_market_pct_snapshot()` 取数**，结构性保证父子对账一致。无成交额的标的（停牌）→ 面积下限 0.5（亿）保可见，tooltip 如实显示真实值。
3. **机会评分口径（展示面用词边界，CLAUDE.md 纪律）**：
   - 本页是**研究评分卡/展示面** → 只说位置（「综合位置靠前/居中/靠后」），**禁止出现「买入/卖出/建仓」**（那是执行面语言）
   - `rank_pct` 分母 = **当日有该因子值的全市场港股**（不是指数成分，也不是「全市场应有标的」），页面/API 响应标注分母口径
   - **缺失一律 `—`，绝不显示成 0**（0 在评分语义里是「最低分」，与「无数据」完全不同）
   - 仙股过滤：价格 < 0.5 港元、当日成交额 < 5000 万港元、上市不足 120 交易日（mom_ret_120d 缺失）→ **不进机会榜**（可仍出现在热力图 L2）
4. **南向持股**：sb_pct 单位是「占总股本百分比」（样本 0.0170=1.7%）；`sb_consec_up` 符号语义（连增/连减天数）实施首步核实后写死注释。
5. **CCASS 因子**：ca_* 基于披露前 10 席位（ca_top10_pct=前 10 席位合计持股占比）；`ca_disclosed_sum`(0.65)=当只股票披露量占股本比 —— **披露覆盖不完整是制度性事实**，集中度解读时口径写成「披露口径下的前 10 席位占比」。
6. **新鲜度如实标注**：任何消费停更数据的卡（AH 溢价 08-27、估值快照 09-12、分析师 09-12）必须显示数据日期徽标（复用 `DateBadge`），AH 溢价卡加「该数据源已停止更新」提示条。
7. **行业聚合**：行业机会分 = 成分机会分**中位数**（不用均值，避免单票拉动）；行业成分 < 8 只不进行业榜；行业层同时披露「机会宽度」= 成分分 ≥ 70 的占比。

## 五、机会评分设计（机会雷达）

### 5.1 六柱合成（个股，全市场横截面分位 0–100）

数据源：当日 `l1_factors` ⊗ `south_factors` ⊗ `ccass_factors`（by symbol 左连），行情快照作门槛过滤。

| 柱 | 成分 | 方向 | 权重 |
|----|------|------|-----|
| **动量 M** | rank_pct(mom_ret_20d)、rank_pct(mom_ret_60d) 均值 | 正向 | 30% |
| **趋势质量 T** | rank_pct(trend_r2_20)、rank_pct(price_position_20) 均值 | 正向 | 20% |
| **南向 S** | rank_pct(sb_pct_d5)、rank_pct(sb_pct_z20) 均值 | 正向 | 15% |
| **筹码 C** | rank_pct(ca_top10_pct_d5)、rank_pct(ca_new_entrants_1d) 均值 | 正向 | 10% |
| **流动性 L** | rank_pct(liq_amount_ratio_5)、100−rank_pct(liq_amihud_20) 均值 | 正向 | 15% |
| **风险 R** | 100 − mean(rank_pct(vol_downside_20), rank_pct(vol_atr_14)) | 正向（低波动给高分） | 10% |

- **综合分 = 0.30M + 0.20T + 0.15S + 0.10C + 0.15L + 0.10R**
- **柱级缺失 → 该柱按中性 50 分计入**（不奖不罚），响应里带 `pillars_covered`（有效柱数）；覆盖 < 4 柱不进榜
- 权重是**初始先验**，S1 阶段用 2026-07~09 历史分区做横截面 IC 快测（月末因子分 vs 未来 5/20 日收益 rank IC），如有明确方向性问题（如某柱长期负 IC）则调整权重或反向，并把实测记录写进本文档「实施状态」

### 5.2 行业聚合（机会行业榜）

- 行业机会分 = 成分（价格/流动性门槛过滤后）机会分**中位数**，成分 < 8 只有效标的的行业不进榜
- 附属柱：行业南向（Σ sb_pct_d5 成分加权）、领涨龙头、机会宽度（成分分 ≥ 70 占比）
- 输出 Top 12，每行带 3 个龙头个股（可点击弹窗）

### 5.3 风险警示榜（对称口径）

- 近 5 日动量分位 < 20 **且** 波动抬升（vol_atr_14 分位 > 80）**且**（南向 5 日减持 或 ccass 筹码发散 ca_exits_1d > 0）→ 按「风险分」排序
- 用途文案：**「近期弱势 + 波动抬升 + 筹码/资金撤离线索」**，不做操作建议

### 5.4 可解释性输出（每只入榜个股）

```
{symbol, name, sector, opp_score: 78.4, pct_change: 3.2, amount_yi: 12.4,
 pillars: {mom: 82, trend: 74, south: 91, ccass: 63, liq: 70, risk: 55},
 pillars_covered: 6, tags: ["南向5日增持", "趋势延续", "量能放大"],
 rank_in_sector: 2, sector_size: 34}
```

`tags` 由分柱阈值机械生成（柱 ≥ 80 → 触发标签，如「南向5日增持」「筹码集中」「低冲击」），**标签是事实陈述不是评价**。

### 8.3 口径修正与关键实现偏差

- **日期输出边界**：快照/分区名是紧凑 `YYYYMMDD`，所有 API 输出经 `market_days.iso_date()` 归一为 ISO（`trade_date`、`data_as_of` 四处）。**坑**：修正后需热加载 api 子进程才生效（磁盘码正确 ≠ 运行进程已加载新码），实测确认五端点全部输出 `2026-10-14`。
- **行业名口径**：热力图/drill 的行业名是**恒生二级行业**（专业零售 / 软件服务 / 汽车 / 药品及生物科技 …，31 个），非「资讯科技业」类一级名。drill 按二级名精确匹配，未知名 404。
- **候选池内截面重标定**：六柱均值合成分天然集中 35–65（中心极限），已重标定为候选池内截面分位 0–100，与平台研究评分口径一致；非候选标的 NaN 不入榜。实测候选池 295/2170 只（门槛：价格≥0.5 港元、成交额≥0.5 亿、上市≥120 交易日）。
- **真 bug（单测抓到并修复）**：`HkHeatmapDrillCard` 机会分按需拉取的 effect 用「重跑即取消」旗标会导致自取消——effect 内 `setOppLoading(true)` 触发自身重跑，cleanup 把自身请求结果丢弃、loading 卡真（分数着色永不生效）。修复为 `oppRequestedRef` 一次性门 + `mountedRef` 仅在卸载时停写，失败允许下次重试。
- **展示面词汇纪律**：机会雷达全链无「买入/卖出」执行词、无「前 N%/后 N%」百分比标签（连续多轮 grep + 单测钉住）。
