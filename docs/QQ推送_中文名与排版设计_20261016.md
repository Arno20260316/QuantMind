## 2. 名称解析设计

### 2.1 数据源实况（已实测，非推测）

| 市场 | 数据源 | 键形态 | 中文名覆盖 |
|------|--------|--------|-----------|
| A股 | `data/stocks/stocks_index.json`（`stock_name_mapper`，现役） | 后缀/前缀/裸码均可 | 实测 `中国核电`/`国轩高科`/`唐山港` ✓ |
| 港股 | `{QM_QUANTHK_DATA_DIR}/2_base_sector/security_master/data.parquet` | 4 位补零 `0700.HK` | **2814/2814 = 100%**（`0700.HK 腾讯控股`） |
| 美股 | `{QM_QUANTUS_DATA_DIR}/2_base_sector/security_master/data.parquet` | ticker | **517/517 = 100%**（`ORCL 甲骨文`、`NVDA 英伟达`） |
| 指数 | 无外部源 → 内置表（约 14 条） | `000001.SH` 等 | 手工维护 |

关键巧合（省掉一层归一）：速览缓冲里港股的形态就是 `2555.HK`（4 位），
与 security_master 键**同形直查**；美股裸 ticker 同理。

### 2.2 新模块 `backend/shared/stock_display_name.py`

```python
resolve(symbol, hint="") -> str      # "" 表示查无名称，不编造
identity(symbol, hint="") -> str     # "国轩高科(SZ002074)" / 缺名时仅 "SZ002074"
```

- 四层：`hint`（调用方已持有，如 alerts.stock_name）→ A股 mapper →
  港/美 security_master（惰性加载 + 进程内缓存 + 文件 mtime 失效）→ 指数表 → `""`
- 显示代码形态：A股统一前缀式 `SH601857`（`StockCodeUtil.to_prefix`）；
  港股 `2555.HK`（与数据同形）；美股 ticker 大写。查找前对常见变体归一
  （`HK.0700`/`HK0700`/`0700` → `0700.HK`）。
- 纪律：O(1) 字典查询（每 3s 的行情循环里也安全）；任何异常只 log 一次并
  降级为无名称；**不编造、不 mock、不把代码当名字回填**。
- 为什么不复用 api 侧 `market_analysis_shared/names.py`：那份契约是
  「查不到回退 symbol 本身」（展示非空），QQ 侧契约是「查不到只显示代码」，
  否则会出现 `2555.HK(2555.HK)`；数据源相同，语义不同，故新模块。

## 3. 卡片排版规范 v1

### 3.1 两种骨架

```
【单事件卡】标题行
正文 1–4 行（「｜」分隔字段）
（可选尾注：详情见 交易台 › {页面}）

【批量卡】标题行
━━━━━━━━━━━━━━（━×14）
条目行（≤15 条）
━━━━━━━━━━━━━━
另有 N 条 · 交易台 › {页面}
```

QQ 正文一律纯文本构图（分隔线/箭头/方括号承担结构）；
keeper 通道的 `**加粗**` 仅作点缀，被平台剥离不影响读感。

### 3.2 标题词表

| 场景 | 形如 | 变化 |
|------|------|------|
| 成交回执 | `▲ 买入 中国核电(SH601985) 400股 @¥9.41` | 保留 |
| 单股风控提醒（止损止盈/策略/哨兵直发） | `⚠️ 止损止盈 · 国轩高科(SZ002074)` | **改**（原名裸码、无图标） |
| 持仓情报（速览级异动） | `📌 持仓情报 · A股 · N 条` | 保留 |
| 持仓预警（分数类） | `🔔 持仓预警 · N 条` | 保留 |
| 情报速览 | `📰 情报速览 · A股 · 盘后 · 15:15 · 43条` | **改**（A股卡补市场词消歧） |
| 决策轮摘要 | `决策轮摘要 · 09:35 rebalance「pro」` | 保留 |
| 收盘收益 / 值班摘要 / 收盘复盘 | `收盘收益 · 2026-10-15` / `值班摘要 · …` / `📋 收盘复盘 · 10-15` | 保留 |
| 系统告警 | `[trading]` / `[health]` 前缀 | 保留（grep 用） |

### 3.3 行文法

- 条目行：`{箭头}{身份} {事实} · {标签}`；箭头 ▼▲◆⚑• 只表方向/类别（展示面纪律）
- 行总长 ≤ 42 字：超出截**事实**保留 ` · 标签`，以 `…` 收尾
- 字段内用 ` ｜ ` 分隔（全角竖线，两侧空格）

### 3.4 数字与货币

- 币种前缀随市场：A股 `¥` / 港股 `HK$` / 美股 `$`（`@¥9.41`、`@HK$465.5`）
- 金额千分位；百分比两位小数
- 分数精度沿用各生产者现口径，同一卡片内一致（不跨卡强改，避免动数值语义）
