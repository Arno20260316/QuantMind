## 三、差距清单与修复设计

### F1 训练页股票池市场错配（正确性，已证实）

- **位置**：`ModelTrainingPage.tsx:1380`
  `market={trainingMarket === 'CN' || trainingMarket === 'CUSTOM' ? 'CN' : undefined}`
- **现状**：HK/US/FUTURES 传 `undefined` → 弹窗默认值 `'CN'`（`StockPoolPickerModal.tsx:63`）→ **非 A 股用户看到并选中 A 股池**。
- **危害**：后端 `pool_binding` 无市场校验，A 股成分会随训练载荷带进 HK/US/FUTURES 训练——因子表 join 落空轻则失败、重则静默错训。静默错配是机构级最忌。
- **修**：新增纯函数 `resolveTrainingPoolMarket(trainingMarket)`（CUSTOM→'CN'，其余原样，`trainingUtils.tsx`），调用点替换；单测六市场逐一断言。
- **期货**：API 返回空列表 → 弹窗既有诚实空态「暂无可用股票池」+ 指路后台，不再显示 A 股池。

### F2 覆盖日历硬编码 SSE（正确性）

- **位置**：`InferenceCoveragePanel.tsx:102` `batchCheckTradingDays('SSE', allDates)`；`:181` 文案「（`SSE` 日历）」
- **现状**：面板唯一调用方是 `ModelRegistryPage.tsx:897`（不传日历）→ 港股/美股/期货模型的覆盖日历都拿**上交所日历**判交易日。
- **危害**：美股感恩节/圣诞、香港假期被标成「缺口日」（永远补不上）；中国假期对美股被当交易日。日历是覆盖判定的尺子，尺子错了整个面板结论错。
- **修**：新增 `calendar?: string` prop（默认 `'SSE'` 保持兼容）；`ModelRegistryPage` 传 `marketConfig.calendar`（管理页模型列表已按市场过滤 :167-178，selectedModel 必属当前市场 → 日历一致）；`'24/7'`（加密）本地全开不调后端；文案随 calendar。
- **后端**：`trading_calendar.py` 别名层（SSE/HKEX/NYSE/CME/FUTURES→CME）在 0e8b3a1d 已就绪，零改动。

### F3 目录加载失败回退内置字段（诚实性）

- **位置**：`ModelTrainingPage.tsx:565-581`
- **现状**：CN/CUSTOM 禁回退（正确）；HK/US/CRYPTO/FUTURES 失败时回落 `DEFAULT_FEATURE_CATEGORIES`（A 股形态字段）+「特征字典加载失败，已回退到内置字段」toast。
- **危害**：六市场全是 QuantDB 直读市场，内置预设不是任何市场的已发布契约；`isDirectCatalogReady` 本就锁死开始按钮 → 回落只制造「有特征可选」的假象。CN/CUSTOM 的注释写得很清楚：「拿 A 股预设去猜是在编造特征」——同一理由适用于所有市场。
- **修**：catch 分支统一为「目录未就绪=不回落」（清空特征 + `console.warn` 留痕，页面以「目录未就绪」呈现）。删除死分支涉及的 import。

### F4 空目录用 PRESET 造勾选（诚实性）

- **位置**：`trainingUtils.tsx:1176-1205` `resolveDefaultSelectedFeatures`
- **现状**：catalog 为空（期货未发布目录）→ `hasAnyFlag=false` → `availableKeys` 空 → `valid=[]` → **`return valid.length > 0 ? valid : preset` 把 20 个期货预设键凭空勾上**。
- **修**：函数开头补不变量——`categories` 无任何特征 → `return []`（空目录是显式答案，不是「用预设猜」的场景）。「有特征但无 flag」的旧后端兜底逻辑保留（行为不变，回归护栏锁）。
- **单测**：空目录对 US/HK/FUTURES 一律 `[]`；有特征无 flag 保留 PRESET 过滤行为。

### F5 请求预览基准回退硬编码（展示）

- **位置**：`TrainingConsole.tsx:273` `context?.benchmark || '000300.SH'`
- **现状**：回退值格式也错（正确格式 `SH000300`），且不随市场。
- **修**：回退改 `getMarketConfig(context?.market || 'CN').benchmark`。payload 的 benchmark 由 `SET_MARKET_CONTEXT` 恒填，回退只是显示保险。

### F6 结果视图缺 CUSTOM 词条（展示）

- **位置**：`TrainingResultView.tsx:30-36` `MARKET_LABELS`（5 市场）
- **修**：`+ CUSTOM: '自定义市场'`；导出常量并加「六词表全覆盖」单测（以 `TRAINING_MARKET_OPTIONS` 为全集断言，防再漏）。

### F7 训练页市场下拉不随 CRYPTO 开关（一致性）

- **位置**：`ModelTrainingPage.tsx:1045` `options={TRAINING_MARKET_OPTIONS}`
- **现状**：生产构建顶栏无「区块链」但训练页下拉有（`uiSlice.ts:38` 与 `MarketSelector.tsx:23` 都已过 `isMarketEnabled`，训练页漏了）。
- **修**：下拉 options 过 `isMarketEnabled` 过滤；`parseTrainingConfig:958` 市场校验同步加 `isMarketEnabled`（拒绝导入当前构建未启用市场的配置，文案「配置中的市场标识无效或当前构建未启用该市场」）。
- **保留**：`resolveTrainingMarket` 词表语义不变（CUSTOM 覆盖等已有测试锁）。

### F8 模型广场市场默认值（分层）

- **位置**：`ModelHubPage.tsx:26` `useState('ALL')`
- **修**：初值取全局 `currentMarket`（从模型管理页进广场先看本市场）；保留本地下拉可切 `ALL` 跨市场浏览（广场属性）。**不做随全局实时跟随**——与页内显式下拉双控件打架，浏览中切筛选是意外。

### F9 期货诚实面（验收面，非缺陷）

- 训练页切期货已可得（实测代码路径）：数据源下拉出 `l1_factors`（ready）、警告 chip「尚未发布因子目录 →」链后台训练数据集、覆盖区间接真实 coverage、开始训练被 `isDirectCatalogReady` 锁死并给出原因提示。
- 本轮**不改**这块行为，只纳入 e2e 断言（证明「阻塞但可见、可行动」）。
- **期货启用一步（运维动作，本轮不代拍）**：后台「数据管理 → 训练服务/模型训练数据集」`market=FUTURES` 刷新字段 + 发布目录 → 训练页解锁 → 训首个 `mdl_futures_*`。

### F10 目录默认勾选在运行被取消时丢失（正确性，实施中发现）

- **位置**：`ModelTrainingPage.tsx` 目录加载 effect——`catalogAnchorKeyRef.current = anchorKey` 原登记在首个 `await` **之前**，而 `active` 中止守卫要到 await **之后**才检查。
- **根因**：被 cleanup 取消的运行已提前消费「换锚」信号；存活的重跑 `anchorChanged=false` 落「保留当前勾选」分支 → **目录默认勾选永远不落地**（只保留 reducer 初始/预设值）。
- **复现**：开发态（`main.tsx:62` StrictMode 双跑 effect）**100% 命中**——CN 特征数=0（reducer 初始 `[]`）、US/HK 停在内置预设 20（目录 default_true 实为 19）。生产单跑常规路径不触发；但同根因在 `factorSource`/附加库自愈改写依赖、首跑于 await 前被取消时同样命中（extras 自愈的 `setExtraFactorSources` 在首个 await 前）。
- **修**：登记移到决策点——最后一个 `active` 检查之后（此后无 await，登记与勾选决策同帧），只有活着走到决策点的运行才登记锚。判定仍用「进入时的已登记锚」。
- **验证**：e2e 四市场实测 CN=42 / HK=19 / US=19（=各目录 `default_true` 计数）、FUTURES=0；修复前同探针 CN=0 / US=20。
