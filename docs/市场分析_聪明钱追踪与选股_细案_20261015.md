# 市场分析（A股）· 聪明钱追踪与选股 — 实施细案

> 2026-10-15 · 状态：待实施 · 口径：CN（A股）
> 需求原文：「增加一个聪明钱的选股功能 跟踪统计聪明钱的，专业量化机构设计下。
> 市场分析部分 需要非常专业去统计和分析聪明钱」

---

## 1. 目标与落点决策

**一个数据引擎，两层交付**：

| 层 | 内容 | 落点 |
|---|---|---|
| 选股 | 聪明钱选股榜（复合分降序，可辨柱构成，行点击弹个股终端） | 市场分析（CN）新增 Tab「聪明钱」 |
| 市场统计 | 龙虎榜生态 / 活跃营业部 / 两融 / 北向季度 / 大宗 / 机构调研 全市场统计与趋势 | 同一 Tab 内概览带 + 证据台 |

**为什么放市场分析 Tab（而非投研平台第四数据源）**：

- 用户两句话指向同一引擎（选股 + 市场统计），一个 Tab 内同时满足；
- 既有先例：因子概率板 Tab 本身就是「市场分析里的选股榜」形态（展示面）；
- 投研平台 `ResearchPlatformPage.tsx` 3695 行单体，插第四数据源要动
  `DataSourceTab` 类型 + 三处表分支 + fetcher，风险大且收益重复（该页行数据
  已带 `mainFlow/instOwnership`）；
- 投研平台接入留作 v2（届时服务端已就绪，前端只需加数据源分支）。

**命名**：全库 grep「smart_money/聪明钱」零命中，无冲突。

**单位纪律（交叉验证过）**：龙虎榜家族金额=元；大宗 mrtj 成交总量=万股、成交总额=万元、
折溢率与占流通市值比为小数（如 -0.2165=-21.65%）；调研为家数。写库前用
「净买额/成交额≈净买额占比」恒等式自检（同 `quantdb_flow_units` 思路）。

**前向收益列封存规则（硬）**：`上榜后1日/2日/5日/10日` 是东财前向收益，
**只可展示（个股档案「上榜后表现」）、绝不可入信号或入验证收益**（验证收益一律
自算 qfq close）。同步时重命名 `fwd_ret_1d/2d/5d/10d`，信号构建器显式排除
`fwd_*` 前缀列，并留单测钉死。

### 2.4 采集脚本 `backend/scripts/smart_money_sync.py`

- **水位续跑**：从 `_sync_meta.json` 各表 last_date − 3 天（重叠窗口，幂等覆盖）拉到
  「最近一个已收盘交易日」；lhb/dzjy 四表按月切片调区间接口；`survey` 走上游
  「公告日>date」近 365 天滚动全量语义 → **单次调用**（逐日循环=每次重下同一份
  近一年快照，纯冗余；2025-10-16 之前的调研上游不供，本地 parquet 自首采起自行
  累积，历史越攒越长）。
- **幂等**：读旧文件 → concat 新数据 → 按业务键去重（如 lhb_detail 按
  `date+symbol+上榜原因`）→ 原子替换（tmp+rename）+ `_sync_meta.json` 原子写。
- **重试**：单切片 3 次退避（东财偶发 SSL EOF）；失败切片不推进水位，下次自愈。
- `--backfill-start 2024-01-01` / `--dataset lhb_inst` / `--dry-run` 三个参数。
- akshare 只在容器内跑（依赖既有 QuantDB/akshare 环境），不引入新依赖。

## 3. 信号设计（专业口径）

### 3.1 分层与 P/C/E 分级

| 层 | 信号族 | 分级 | 说明 |
|---|---|---|---|
| S1 | **机构席位**（lhb_inst） | **P 候选柱** | 机构净买额、机构净买额占总成交比、买卖席位差 |
| S2 | **榜单整体**（lhb_detail） | **P 候选柱** | 龙虎榜净买额占比（捕捉非机构主导的席位合力；与 S1 做相关塌缩） |
| S3 | 北向季度（hsgt_north） | **C 背书** | 季度披露，7 个季度无统计功效，仅列示 |
| S4 | 两融（margin_trading） | **P 候选柱** | 融资净买入 5 日累计 z20、融资余额 20 日变化率 |
| S5 | L2 大单 | **C 背景（否决策已决）** | 证据台引述既有否决结论，不重复进分 |
| S6 | 大宗交易（block_trade） | **P 候选柱** | 5 日成交额/流通市值、5 日加权折溢率 |
| S7 | 机构调研（survey） | **P 候选柱** | 90 日接待机构家数、最近调研日距 |

### 3.2 池定义（选股榜样本域）

**事件驱动池**：最近 **5 个交易日**内发生任一聪明钱事件的股票
（龙虎榜上榜 ∪ 机构席位净买 ∪ 大宗交易 ∪ 机构调研）∪ 两融异动（|净买 5 日 z20| ≥ 2）。
每日重算；池规模预期 100–400 只。榜单在池内按复合分降序。

> 不做"全市场逐日评分"：非事件股五柱全缺，分数只能由填充分构成，榜单会被
> 两融单柱主导，是伪信号。

### 3.3 柱与复合分

- **柱候选**（每族先取 1–2 个强代理，最终入柱由验证闸门裁定）：
  1. `inst_net_ratio_5d` 机构净买额占总成交比 5 日累计
  2. `inst_net_buy_5d_z` 机构净买额 5 日累计 z20
  3. `lhb_net_ratio_5d` 榜单净买额占比 5 日累计（与 1 相关塌缩，ρ>0.8 留强者）
  4. `margin_net_5d_z` 融资净买入 5 日累计 z20
  5. `margin_bal_chg_20d` 融资余额 20 日变化率
  6. `dzjy_amount_ratio_5d` 大宗 5 日成交额/流通市值累计
  7. `dzjy_premium_5d` 大宗 5 日折溢率（按成交额加权）
  8. `survey_inst_90d` 90 日接待机构家数
- **截面分位重标定**：每柱 → 当日**池内有值成员**截面分位 0–100（HK 六柱同法）。
- **方向对齐**（2026-10-16 口径补钉，HK 先例 `hk_opportunity.py:151`「方向=实测方向」）：
  每柱分位按**该柱 h10 实测 IC 符号**对齐——负向柱取 `100−分位`，使柱分高 =
  历史有利方向。方向随 `evidence.json` 逐柱披露（signals[].direction）。
  无此处理时负向柱（本轮 4 柱中 3 柱）会把复合分带向反预测方向。
- **复合分** = 入柱（方向对齐后）等权均值；**缺失柱记 50 且披露**
  `pillars_covered = 非填充柱数/总柱数`
  （HK 模式：缺失一律记覆盖数，绝不把缺失当 0；界面上分位缺失显示「—」）。
- **反前视**：所有信号仅用截至 T 日盘后可得数据（龙虎榜/调研 T 日晚发布）；
  分数是「截至 T 日收盘可得」的当日快照。

### 3.4 个股事件时间线（选股榜下钻，不依赖柱）

按 symbol 从 5 张原始表取近 20 事件记录：上榜日/上榜原因/解读文本/机构净买额/
榜单净买额/上榜后表现（fwd_* 展示列，标注「历史回溯统计，非预测」）/
大宗折溢率/调研家数 + 北向季度持仓变化序列。

## 4. 验证协议（入柱闸门，照 HK 六柱方法论）

脚本：`backend/scripts/smart_money_validate.py`（结构照抄
`backend/scripts/hk_opportunity_ic_check.py`，双过闸判据一字不改）：

1. **收益口径**：`fwd(t,h) = close[t+h]/close[t+1] − 1`（保守：信号日 T 盘后可得 →
   T+1 收盘入场），clip(-0.5, +1.0)，收益截尾防仙股；close 用 QuantDB qfq。
2. **日度秩 IC**（Spearman 流）+ **五分位超额**（q1..q5，对当日中位数）。
3. **双过闸 `tail_ok`**：`sign(IC)==sign(q5−q1)` 且 `|IC|≥0.01` 且 `|q5−q1|>1bp`
   且 `n_days≥60`；horizon 取 5/10 两档。
4. **事件条件因子特则**：LHB/大宗/调研类信号仅在事件股上有值（非事件股 NaN 不参与），
   日截面样本数门槛降为 `MIN_NAMES_PER_DAY=30`（实测 LHB 日 50–90 只）；两融/全市场
   类维持 100。此特则与理由写入 evidence.json 披露。
5. **相关塌缩**：入柱候选两两截面秩相关，ρ>0.8 的同族信号留 |IC| 强者（防重复计权）。
6. **分年稳定性**：IC 按 2024/2025/2026 分段报告（先例教训：板块 streak 信号
   fwd3 全窗+28.4bp 但分年 −9/−3/+19bp，必须披露分年）。
7. **窗口**：2024-01-01 起（与 LHB 回补深度对齐；两融更早但不跨制度窗口比较）。
8. **复合分验证（第二轮）**：build 回填 40 日后，对 `scores/dt=*` 的复合分矩阵
   跑同一套 `_evaluate`（池内 IC），结果 + 逐柱结果一并写 `evidence.json`。
9. **产出**：`evidence.json`（每信号 IC/ICIR/pos_rate/q1..q5/分年/tail_ok/入柱裁定）
   + `logs/smart_money_validate.csv`；页面证据台仅读 evidence.json。

**闸门是行刑官不是选择题**：未过闸候选一律进「否决清单」公开展示（含数值），
过闸才入柱。若某族全军覆没（如 L2 前例），该族降为 C 级只列示事实。

### 6.2 展示面/执行面用词纪律（硬）

- 分与柱是**研究评分**，页面固定披露「聪明钱分＝席位/资金行为统计评分，
  非模型预测、非交易指令」（照 HK「研究评分卡」横幅）；
- 事实列用数据原名语义（「机构净买额」「融资净买入」——与资金流全景「净流入」
  同先例），**不出现**「买入信号/推荐/建议」；
- 禁用「前 N%」话术（信号分位路径不一），位置感用「靠前/居中/靠后」或 0–100 分；
- 上榜后表现列头注明「历史回溯统计（非预测）」；
- UI 禁内部工单号。
