## 1. 侦查结论（截图 /tmp/recon_arena_chat*.png、/tmp/recon_rss_news.png）

### 1.1 模型对话：机器输出直出人眼（根因）

- agent 现为纯结构化 JSON 输出（`{"decisions":[{"action":"sell","code":"600338.SH",...}]}`），
  不含 `【总体总结】/①②③④` 标记 → `parseAnalysis` 走「无标记」回退：
  `summary = 首段(260)` = **原始 JSON 串**；`reasoning = 全文` 再抄一遍 JSON。
- 实测截图：每张折叠卡「总结」条 = `{"decisions": [{"action": "sell", "code": ...`。
  交易决策段解析正常（JSON→决策卡的路径是好的）——坏的只有总结/推理两段。
- 对照质量线：新闻 tab 的协议化摘要（`… · 主线 2 · 风险 2 · 置信 0.35`）就是「给人看」的标准。
- 次要：卡头日期是 `10-15T09:35`（ISO 裸截的 `T` 没处理）；且 `slice(5,16)` 对
  **aware UTC** 时间戳直接截 UTC 数字（`utils/datetime.ts` 的口径是 aware → 北京墙钟）。
  卡片除 2px 边框外无模型色身份。

### 1.2 RSS 资讯桌面

- 分类行铺满 **两行 ~22 个 chip**（固定 10 + top_events 全部），视觉噪音占掉整条带宽。
- 已读条目整行 `opacity: .65` → 标题发灰像坏图；读/未读节奏失衡（未读加粗深色 + 已读洗白）。
- 摘要处漏出源站占位符「点击标题查看详细内容」（backend/electron 源码里均无此字面量，
  是 Huntly 库里的上游 feed 数据；列表里显示 = 零信息量还显敷衍）。
- 右栏 40% 空白（「选择文章查看正文」小字）——桌面阅读器没有任何内容落位，像没做完。
- 左栏：徽标贴边有裁切风险；其余（长名省略）可接受。

## 2. 改法

### A. 对话解析人性化 — `arena/utils/parseAnalysis.ts`（PATCHES ×3）

A1. `extractJsonBlocks` 重构为 `scanJsonBlocks`（返回 `{value,start,end}`），旧函数变 wrapper
    —— 剥离 JSON 区段需要偏移量。
A2. 「无标记」分支四级递降（原「摘要=首段」保留为其中一级）：
    1. JSON 内的字符串字段 `summary/overall/market_view/总体总结…` → 摘要；
    2. **剥离 JSON 区段后的散文首段**（真散文才用；以 `{`/`[` 开头视作机器串）→ 摘要；
    3. 解出决策项 → **决策扼要行**：`本轮 3 项决策：卖出 600338.SH 100% · 买入 601985.SH 10% …`；
    4. 都不行且确实有 JSON 样内容 → `结构化输出未能解析（展开查看原始记录）`。
    推理论证段：JSON 内 `analysis/reasoning…` 字段 → 否则散文（摘要取首段时推理只留其余，
    两段不重叠）→ 纯 JSON 轮**置空**（该节自动隐藏，不再回抄）。
A3. 模块头 docstring 的回退说明同步更新（旧文案已失真）。

### B. ChatStream 结构小补丁（PATCHES ×3 + datetime ×1）

B1. 卡头日期：裸 `slice(5,16)` → `fmtMonthDayClock()`（新增于 `arena/utils/datetime.ts`）：
    aware → 北京墙钟、naive 原样、年月日短出 `10-15 09:35`、纯日期退化为 `08-28`。
B2. 卡片注入 `--mc-accent`（模型色变量）+ `type CSSProperties` 导入 —— 主题层做卡身份用。

### C. 视觉打磨 — `qm-arena-theme.css`（手写层，追加「模型对话卡」一节）

语言不新造（白底/黑描边/Courier/涨红跌绿不动），只做层级：

- 卡头：模型色 4% 淡底（hover 9%）→ 一屏十几张卡靠颜色一眼分得开；
- 总结条（折叠态唯一常读区）：字号 12.5 / 行高 1.75 / 深灰；**折叠时限 4 行**（展开不截）；
- 决策迷你卡：pct 改等宽数字描边 pill；行距微调；
- 小节头字号/留白微调（含 hover 保持，防高特异性静默压掉页面 hover）。

选择器一律 `.qm-arena-root .mc-list .mc-card …`(0,3,0) 压过随 chunk 晚载的 ModelChat.css (0,2,0)。

### D. RSS 桌面 — `NewsPanel.tsx` + `news-panel.css`

D1. 分类行折叠：固定 10 个常显；热词 chip 默认只出 4 个（含已选中的），
    其余收在「更多分类 (N) ▾」后。
D2. 已读态重做：去整行 opacity；已读=标题灰 `#94a3b8`+常规字重，未读=深色+加粗——节奏立起来。
D3. 占位摘要滤除：新增 `features/news/utils/articleDisplay.ts::isPlaceholderSummary()`
    （「点击标题查看详细内容」及变体、与标题相同 → 列表不渲染该行；仅展示层，不动数据）。
D4. 桌面右栏自动开第一篇：无选中且有列表时自动选中 `articles[0]` 并加载详情；
    **不标已读**（`autoOpenRef` 命中的这篇跳过 `markRead`）——阅读器惯例填满版面，不动已读语义。
D5. 杂项：左栏右内边距防徽标裁切；统计数字千分位；摘要截断符 `...`→`…`。

## 3. 测试与验收

- **vitest**：新增 `agent-arena/__tests__/parseAnalysis.test.ts`（纯 JSON→扼要行且无 `{`；
  纯 JSON 推理置空；散文+JSON 摘要取散文/推理剥 JSON；JSON summary 字段优先；坏 JSON→说明句）；
  `ChatStream.test.tsx` 增「总结条不出现原始 JSON」渲染断言；`articleDisplay` 占位符单测。
- **`npx vitest run port-parity`** 必须绿（PATCHES ↔ 镜像字节一致）。
- **typecheck** → `bash scripts/deploy_frontend.sh --allow-local-live --allow-doc-mining`。
- **实机探针** `electron/tests/probe_chat_digest_news_desktop.mjs`：
  ① 模型对话卡片总结条与卡头均无原始 JSON（`{"`）残留、日期无 `T\d\d:`；
  ② RSS 分类行 chip ≤16 且「更多分类」按钮存在；
  ③ 列表占位摘要滤除（与同页 API 数据对账，防真空通过）；
  ④ 右栏自动出第一篇正文（标题非空）；⑤ 无页面级 JS 错误。

## 4. 边界

- 全部前端改动；后端零改动 → 无热重载风险，也不影响正在跑的全量 pytest。

- 不改已读/未读**数据**语义（占位摘要仅展示层滤除；自动开篇不标已读）。
- 对话解析改动对新闻 tab / 模型详情页是同一份实现，三处一并受益。
