# 港股聪明钱 · 机构级升级细案（v2）

- 日期：2026-10-16（周五）｜状态：设计定稿，即日实施
- 范围：只动港股聪明钱（`backend/shared/hk_smart_money/`、`market_analysis_hk/`、`scripts/hk_smart_money_*`、`electron/src/features/market-analysis-hk/`）；A 股聪明钱与 `market_analysis_us/` 不碰。
- 缘起（用户三点不满 → 侦查实锤）：
  1. **「看不出哪些机构更有优势」**——现榜按 `shrunk_exc_bp` 排序，小样本浮顶实锤：top8 含 n=9/10/13/19 席（雅景 n=9 t=1.49、亞太 n=10 t=2.10），与 n=170~3721 的扎实席位（t=3.9~7.8）混排，噪声与证据不可分。
  2. **「数据统计不够专业」**——席位统计只有 fwd_exc_10 一个 horizon、等权一档口径；事件仓已封存的 `fwd_exc_5/20`、`fwd_ret_5/20`、金额权重维度全部闲置；且 `seats.parquet` 只在 validate 标定时生成，**每日 build 不更新**（结构上会随信息推进陈旧）。
  3. **「界面不专业、要标签切换、图表多、统一美观」**——现面板一列堆叠 5 卡约 2.5–3 屏、挂载即全量取数、目录内 0 个 tablist、**0 张图表**（trends 60 日序列、q1–q5、correlation 等图数据在响应里闲置）。

## 1. 持续性审计：本升级设计的事实背板（必须先读）

对全事件仓（931,291 事件 / 598,587 episode 首日 / 588,507 h10 可测）做前/后半切分（切分日 2025-11-05，前半 227 日），四组实证：

| 检验 | 样本 | 结果 | 含义 |
|---|---|---|---|
| 席位裸超额 前后半秩相关 | 187 席 | Spearman **0.043** | 近乎零 |
| 席位方向命中率 前后半 | 187 席 | Spearman **0.036** | 近乎零 |
| **席位方向技能 h10** 前后半 | 187 席 | Spearman **0.116** | 弱正（四组最强） |
| 席位方向技能 h20 前后半 | 184 席 | Spearman **0.137** | 弱正 |
| 前半年四分位 → 后半年跟随 | 137 席 | 四组 OOS 均超额 0.002%~0.004%（无梯度） | 无跟随价值 |

**类别层方向技能却跨半场稳定**（vw，bp）：

| category | 前半 | 后半 | 解读 |
|---|---|---|---|
| apac | −79.2 | −39.3 | 大额委托持续为反向指标 |
| cn_broker | −56.8 | −16.9 | 同上（执行流特征） |
| hk | −0.8 | −0.9 | ≈0 |
| us_eu | +7.4 | +4.2 | 微正 |

**设计结论（诚实边界，全案前提）**：
- 席位层优势只能做**描述性统计**（历史战绩 + 置信下界 + 样本量纪律），不得表述为可跟随 alpha；界面须把「弱持续」如实上墙（第 5 面），这与平台 `evidence_only=true`（24 信号零过闸）的既有叙事一致。
- **方向技能（买→+exc，卖→−exc）是本特性「机构优势」的正确度量**（持续性强于裸超额与命中率），榜单主排序键从 `shrunk_exc_bp` 换成其 **90% 下界**。
- 类别层负技能是稳定的可讲结构 → 类型效力面的核心图。

**口径与单位对齐实证**：`fwd_exc_*` 为**小数**（信達國際复算 mean=0.05916 ↔ seats `avg_exc_bp=591.6` 逐位吻合；亞太 n=10 行席位级吻合）。席位统计口径 = `episode_lead==1 ∧ ¬transfer_suspect ∧ fwd_exc_10 可测`，本升级沿用不变（只加维度，不改基础过滤）。

## 2. 设计总纲（机构级五原则）

1. **描述与预测分离**：榜单面标注「历史战绩 · 描述性统计」；验证面单独回答「能否复制」。
2. **样本量优先**：主排序 = 90% 置信下界（弱惩罚双刃：小样本下界自然沉底；**n_exc10 < 5 不给下界——正态近似在更小样本失效（n=2 零方差时 SE=0 会伪造 lb=skill 浮顶），「—」比假标 90% 诚实**）；默认门槛 n≥50，chips 可调（30/50/100/全部）。
3. **等权与价值加权并示**：每处战绩同时给 mean 与 vw（|Δvalue| 加权），大钱与笔数分离。
4. **表格与图表分工**：表给精确数字，图给形状（分布、散点、时序）；每图悬停即口径。
5. **口径悬挂制**：每个衍生数字旁挂口径注（词表单源），集中处（第 5 面）完整披露。

## 3. 后端统计层 v2

### 3.1 `stats.seat_metrics` v2 —— seats.parquet 19 → 30 列（不删旧列，保兼容）

新增列（全部按窗口 20/60/all 成套，单位 bp 存库）：

| 列 | 公式 | 用途 |
|---|---|---|
| `skill_bp` | mean(方向技能)，方向技能 = dir==1 ? fwd_exc_10 : −fwd_exc_10 | 榜主指标 |
| `skill_t` | skill_mean / SE(skill) | 显著性展示 |
| `lb_skill_bp` | skill − 1.28×SE（90% 单侧下界；仅 n_exc10 ≥ 5 时给出，更小样本「—」沉底） | **榜主排序键** |
| `vw_skill_bp` | Σ(|Δvalue|×skill) / Σ|Δvalue| | 大钱口径 |
| `exc5_bp` / `exc20_bp` | fwd_exc_5 / fwd_exc_20 均值（裸超额，对照） | 稳健性横看 |
| `buy_exc_bp` / `sell_exc_bp` | 买入事件 / 卖出事件的 fwd_exc_10 均值（各侧原始，不翻符号） | 买卖不对称 |
| `n_symbols` | 该席事件去重标的数 | 专精 vs 分散 |
| `avg_value_m` | mean(|Δvalue|) / 1e6 | 单笔分量级 |

> **实测补记（2026-10-16 真数据重跑）**：① 默认门槛 n_events≥50 下无噪声浮顶——全表
> `n_exc10 < 25 ∧ n_events ≥ 50` 的席位数 = 0，成熟度与样本量同向；② 榜首扎实：
> all 窗 lb 首位 核聚证券 n_exc10=91、skill +428.7bp、t=3.29，前 3 名 t = 3.29/2.20/2.07；
> ③ 下界纪律两态齐备：非空 lb 全部 n_exc10 ≥ 5，空值全落在 0–4（378+133+72+48+38 行）。

### 3.2 生成链迁移（修一个既有暗坑）

`seats.parquet` 现在由 validate 生成 → **v2 起与新增产物一起改由 build 每日生成**（validate 只留信号裁定职责）。
- 依据：build 每日 19:40/21:40 跑（celery），validate 手工跑；席位榜是读侧每日消费的盘点数据，不能挂在校准节奏上。
- 函数仍住 `shared/hk_smart_money/stats.py`（单一实现），build/validate 皆可调；validate 中该步删除。
- 集成测试自洽断言（`latest.as_of == seats.last_event_date.max()` 等）改为 build 语义，当天即成立。

### 3.3 新产物 ×2（均 build 每轮重算，读事件仓封存列，秒级）

1. **`seat_monthly.parquet`**：`participant_id, month(YYYY-MM), n, skill_bp, vw_skill_bp, hit` —— 席位档案抽屉的月度序列数据源（430 席×~12 月，小表）。
2. **`seat_persistence.json`**（allow_nan=False 原子写，同 evidence 惯例）：
   ```json
   {
     "generated_at": "...", "as_of": "...", "split_date": "2025-11-05",
     "scatter": [{"participant_id","name","category","n1","n2","skill1_bp","skill2_bp"}],
     "spearman": {"h10": 0.116, "h20": 0.137, "hit": 0.036},
     "quartiles": [{"q":1,"n_seats","forward_mean_bp","forward_hit","n_events"}],
     "category_halves": [{"category","first_half_vw_skill_bp","second_half_vw_skill_bp","n"}],
     "method": {"scatter":"...","quartile":"...","note":"..."}
   }
   ```
   门槛与本案 §1 实证一致（散点 n1≥20 ∧ n2≥10）。**数字由构建期实算，不写死**。

### 3.4 类别层技能聚合 → 进 `latest.json` 的 categories[]

`overview.categories[]` 每类新增 `skill_bp / vw_skill_bp / n_lead_events`（构建期 6 类聚合）。供首面「类别优势」图与概览带，不另开端点。

### 3.5 API 变更（`market_analysis_hk/hk_smart_money.py`，净增 2 端点、改 2 端点）

| 端点 | 变更 |
|---|---|
| `GET /seats` | ① 响应行加 §3.1 新列；② `sort` 白名单扩为 `lb_skill`（**新默认**）/`skill`/`vw_skill`/`avg_exc`/`shrunk_hit`/`n`；③ `min_events` 默认仍 5（前端默认传 50） |

### 3.6 冻结纪律不变
